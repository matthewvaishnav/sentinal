SENTINEL v1.0.3 - Quick Start Guide
=====================================

Thank you for installing SENTINEL!

WHAT IS SENTINEL?
-----------------
SENTINEL is an intelligent anti-DDoS protection platform that protects
your web applications from bot attacks using neural AI and behavioral
fingerprinting.

GETTING STARTED
---------------
1. SENTINEL has been installed to C:\Program Files\SENTINEL\
2. Start Menu shortcuts have been created
3. The server will run on http://localhost:3000

TO START SENTINEL:
------------------
Option 1 - Command Line (Recommended):
  1. Open Command Prompt or PowerShell
  2. Type: sentinel
  3. Keep the window open
  4. Open browser to: http://localhost:3000/dashboard

DASHBOARD
---------
Access the real-time monitoring dashboard at:
  http://localhost:3000/dashboard

TROUBLESHOOTING
---------------
Q: The window opens and closes immediately
A: You must run from command line to see errors. Common causes:
   - Port 3000 already in use (change PORT in config)
   - Missing configuration file
